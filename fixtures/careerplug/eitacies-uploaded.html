Kubernetes Site Reliability Engineer (Remote)
Location: 100% Remote - United States
We are hiring multiple Site Reliability Engineers to support enterprise Kubernetes platforms running in secure cloud environments. This role focuses on building reliable, scalable, and automated infrastructure using Kubernetes, AWS, Terraform, Linux, and modern DevOps practices.
Openings are available for mid-level, senior, and technical leadership candidates based on experience.

Responsibilities
Design, build, and support production Kubernetes environments
Improve platform reliability through automation
Build Infrastructure as Code using Terraform
Develop automation using Python or Go
Support CI/CD pipelines and deployment automation
Monitor platform health using Prometheus, Grafana, and observability tools
Participate in production support and incident response
Work closely with Platform, Security, and Development teams

Required Skills
Kubernetes, Linux, AWS, Terraform, Python or Go
CI/CD, Prometheus, Grafana, Site Reliability Engineering, Infrastructure Automation

Preferred
FedRAMP, GovCloud, DoD IL5, NIST, ArgoCD, GitOps

This is a remote position.

Compensation: $60.00 - $64.00 per hour
