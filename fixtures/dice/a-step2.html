Summary

Job Title: DevOps Engineer (Multi-Cloud, CI/CD, Secrets Management)

Location: 100% Remote

Interview Process: Video (2 Rounds)

Work Schedule: 100% Remote

Job Description:

  • 12-15 years of experience

  • Design and maintain infrastructure as code (Terraform/Pulumi) and Kubernetes-based deployments across AWS, Azure, and Google Cloud Platform with portability and cost controls.

  • Build CI/CD pipelines for application, model, and data workflows, including automated testing gates, progressive rollouts (canary, blue/green), and fast rollback. Jenkins, puppet, chef, ansible, git actions and workflow etc.

  • Own secrets and credentials management (Vault, cloud KMS/Secrets Manager), key rotation, least-privilege IAM, and secure handling of model API keys.

  • Automate mobile build, signing, and release pipelines (TestFlight, Play Console) alongside web deployments.

  • Implement monitoring, alerting, autoscaling for GPU/inference workloads, DR planning, and DevSecOps scanning (SAST, dependency, container, and IaC checks).

  • Container strategy across clouds

  • Compute, storage and network services across hyperscalers
