Position Summary:


Job Title: Google Cloud Platform Platform Engineer – DevOps

Duration: 12 months (long-term contract)

Work Arrangement: 100% Remote

Client Location: Jersey City, NJ 07310 / New York City, NY 10013

Exprerience: 8-10 Years 

Job Overview:

We are looking for an experienced Google Cloud Platform Platform Engineer with a strong DevOps background, hands-on cloud infrastructure expertise, Terraform, and Python scripting experience.

This role involves building, managing, and automating Google Cloud Platform infrastructure, along with integrating various Google Cloud Platform services, particularly those supporting Data Lakes and Data Engineering environments.

Must Have Requirements:

Strong hands-on experience with Google Cloud Platform (Google Cloud Platform) infrastructure.

Proficiency in Terraform for Infrastructure as Code (IaC).

Strong Python scripting and automation experience.

Hands-on experience with various Google Cloud Platform services.

Exposure to Google Cloud Platform Data Services and Data Engineering.

Experience integrating Google Cloud Platform infrastructure components, particularly for Data Lake and Data Engineering solutions.

 

Important: Hands-on Google Cloud Platform experience is mandatory. AWS or Azure experience alone will not be considered a substitute.
